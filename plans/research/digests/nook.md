# Nook — digest

Source: `plans/research/nook.md` (2026-10-25; `nook-browser/Nook` `develop` @ `242c7fb`, 1.3.0 build 119; plus `nook-browser/www`, GitHub API, live Sparkle feed, HN). **FACT** = primary source; **CLAIM** = the project's own words, unmeasured; **INFERENCE** = researcher's reasoning. The dossier's 42-row Verification section is authoritative.

## In plain English

Nook is a free, open-source Mac browser that copies Arc's sidebar. It is a small Swift app around Apple's web engine, the one in Safari, so the download is 18 MB but Chrome-only sites can break. It has spaces, favorites, pinned tabs, link previews, split view, a mini window for outside links, and Arc import. Its blocker is strong but off by default. Its AI can run on Apple's on-device model with no key. A hidden "Agent space" lets outside coding agents drive the browser without moving your tabs. For rac, the value is ideas, not code: the Agent space, the "did the person name it?" safety check, motion numbers, and tab-file safety rules.

## Key facts

**Identity.** Arc-style macOS browser; SwiftUI/AppKit shell over system `WKWebView` (FACT, `README.md`). GPL-3.0; name, wordmark, icon are Bain Gurley's trademarks, forks must rename (FACT, `LICENSE`, `TRADEMARK.md`). <https://github.com/nook-browser/Nook>; default `develop`. 1,980 stars, 84 forks (API, 2026-10-25). Dormant Dec 2025–Aug 2026; takeover 2026-09-17 after #349. One maintainer: 465 commits since 2026-09-01, 461 by Gurley; ~190 disclose AI help. Nine releases 2026-09-18→10-24; downloads 175–665/version (includes Sparkle updates), 1.0.2 peaked 4,848. No business model, accounts, or paid tier.

**Size and engine.** DMG 18.3 MB (18,251,990 B, FACT); binary 54.2 MB (CLAIM). ~65,600 lines first-party Swift (70,100 with vendored + iOS), 1,500 Rust FFI, 2,500 JS. macOS 15.5+, Apple Silicon only; unreleased iOS 0.1.0 target. System WebKit, no fork or patches; ~20 private selectors (15 literal, ~5 built at run time, e.g. `_setWindowOcclusionDetectionEnabled:`, `_clearBackForwardCache`), plus two AppKit swizzles (title-band drag, `cancelOperation:`) (FACT). INFERENCE: each macOS release risks breakage, and Nook cannot patch WebKit.

**Process.** One app process holds all UI/state on the main actor; pages, extension background pages, and service workers run in WebKit's sandboxed WebContent processes plus its shared networking and GPU processes (FACT, `CLAUDE.md:351,369`). Child processes only for Sparkle XPC, native-messaging hosts, stdio MCP. Not sandboxed; hardened runtime, no JIT exception. Space profile = `WKWebsiteDataStore(forIdentifier: uuid)`; every tab config must be `.copy()`-derived from the extension controller's. One live `WKWebView` per page, moved between windows; others draw a placeholder.

**Features (1.3.0 unless noted).** Sidebar: favorites grid, pinned, tabs, hairline separator. Spaces: accent color, no icon; dots / Ctrl+1–9 / Cmd+Opt+arrows / two-finger swipe. Profiles = spaces sharing cookies/logins/history; extensions, settings, blocker app-wide. Folders depth 5. **Trails**: link-opened tab nests under its opener; Back on a child with no history closes it to the parent. Sidebar hide + edge reveal. On-device organizer (macOS 26 + Apple Intelligence, off). **No auto-archive.** Palette search/url/tab/history only, **no commands**. 14 site-search chips; FTS history; redirect/tracking stripping (blocker on); split 2 panes, magnetic drops; Peek 80%×90%; ATC domain/path→space (subdomains, longest match, never sign-in); Arc import (spaces, nested folders, names, accent, per-profile favorites, extensions by id, member card; no passwords/cookies/history); Safari/Dia import.

**AI.** "Ask Nook" right column reads the page, streams, web-searches (OpenRouter `:online`/Gemini grounding), calls tools. Feature on by default but **column starts closed**; web search off. Providers: Apple `FoundationModels` on-device (default fallback), Gemini, OpenRouter, Ollama (`localhost:11434`, default `llama3`), any OpenAI-compatible endpoint; keys in Keychain. MCP **client** over stdio/SSE. Loop ≤20 rounds, 12 browser tools (navigate, read, click by selector or text, list elements, structured data, in-page search, tabs, selection, JS). No agent mode, plans, cards, or critic (INFERENCE). Modes `auto`/`ask` (**default**)/`disabled`; `ask` prompts navigate/click/new tab/switch tab; "Allow All This Chat" ends prompts; `executeJavaScript` and MCP tools ask even in `auto`; private windows get neither. Approvals are blocking `NSAlert.runModal` "AI Tool Request", Deny first (`AIService.swift:439-482`).

**Injection defenses.** Page content and tool results are wrapped in `page_context_<8 hex>` (fresh suffix per request); the tag is stripped from the text; the system prompt marks it as data. A 22-case on-device eval reportedly obeyed planted text "on every eval run whatever the prompt said" (CLAIM; eval is gitignored). So on-device navigate/click ask even at `auto` unless `personNamed` — the person's own message names the site or button text; selector clicks always ask. `personNamed` uses a seven-entry country-suffix list, not the PSL, and errs toward asking. **Cloud models in `auto` have no such check** (FACT) **and no navigation containment** (INFERENCE).

**Outside agents (DevMCP).** Streamable HTTP MCP on `127.0.0.1:47823/mcp`; 0600 bearer token; non-localhost `Origin` → 403 (host parsed, so `localhost.attacker.example` fails); 30 s/call; **31 tools**. Off unless Developer Mode **and** Browser Control; independent of the AI setting. Tools = the 12 chat tools minus `executeJavaScript`, plus `evaluate`, `download`, `screenshot`, `console`, `network` (`since`), `perf`, blocker ops, `snapshot`, `pick`, `selection`, `reload`, `wait_for_load`, tab/page ops, `user_scripts`. `snapshot`: AX outline (role, name, state), default 300 nodes, cap 2,000, depth 12, changed lines on repeat. `getInteractiveElements`: 50 default, **no cap**. Chat clicks by selector/text, **no ref ids**; chat JS runs mostly in the page's own world, so a hostile page can tamper. Panel: console/network/perf/blocker log/element picker (Cmd+Shift+X, Send to Agent)/docked Web Inspector. No CLI, AppleScript dictionary, URL scheme, mods, or boosts.

**Agent space.** Every tool except `pick`/`selection` acts in a dedicated space: created on first use, last in order, **found by a marker never a name**. It **borrows the logins** of the space open at creation; that link is fixed. Read-only tools (`pages`, `check_urls`, `getTabList`, `clear_page_cache`) do not create it. Agent activity never changes what a window shows. Agent pages get no extensions, history, Peek/mini windows, or other apps, and answer dialogs, file pickers, and auth without UI. The hidden page stays alive by hosting it in the active window at alpha 0, 20,000 pt off left, occlusion detection off; measured 60 fps with IntersectionObserver firing (CLAIM); parked after 30 s idle. Chrome: amber→magenta gradient no user accent can match, framed "Agent" label, pulsing sidebar row. **"The token is the approval"**: `evaluate` runs any JS unprompted (page world by default, isolated on request); `download`/`saveTo` only under `~/Downloads/Nook MCP`. Anyone reading the token file can drive the browser, including Release builds. `pick` waits 25 s for a human click; `selection` returns selector, HTML, changed styles, React/Vue names, errors, screenshot.

**Storage.** No server, accounts, backend, or telemetry in app code (Sparkle profiling off); root `telemetry-id` is read by nothing.

- Spaces/favorites/pinned/folders: `~/Library/Application Support/com.gstudios.nook/Tabs/structure.json` (JSON, `formatVersion`, 30-day tombstones); tabs/device: `…/Tabs/device.json`.
- Backups `…/Tabs/Backups/<yyyy-MM-dd>/` kept 7 days; saves coalesce 500 ms, atomic, flush on quit; a corrupt file loads the newest backup, else read-only mode.
- Order: base-62 fractional keys; a move writes one item.
- History + extensions: `…/default.store` (+`-wal`, `-shm`), SwiftData/SQLite, 100-day retention; mismatch backs up then resets.
- Page text: `…/History/page-text.sqlite`, FTS5, ≤20,000 chars/URL, on by default, skipped for private and Agent pages.
- Session cookies `…/SessionCookies/<space-uuid>.plist` (binary, 0600); website data under `~/Library/WebKit/com.gstudios.nook/`.
- Settings UserDefaults `com.gstudios.nook`; AI config `…/Application Support/Nook/ai_config.json` (no keys); keys/HTTP auth in Keychain; no app-level encryption.
- Three bundle ids in a year; 1.0.x could not auto-update; a shared id means two copies corrupt each other's tabs. iCloud sync is branch-only (`CKSyncEngine`, private DB, `encryptedValues`, 30 s publish).

**Motion** (`NookDesign.swift` unless noted). quick = easeOut 0.12 s (hover, press); standard = smooth 0.22 s (selection, reveal, fold); spring = snappy 0.3 s (palette, dialog, toast, drag reorder, Peek); settle = smooth 0.6 s, separator wave period 1.6 s / amplitude 3 pt / wavelength 56 pt; flight = easeIn 0.6 s. Space swipe: 0.18 s cubic-bezier(0.16, 1, 0.3, 1), one haptic at 15% travel, commit past 30% or 0.8 widths/s. Space change 0.2 s; sidebar show/hide 0.1 s; AI column 0.2 s (move + fade), all easeInOut. Edge reveal easeInOut 0.15 s; 6 pt trigger, 12 pt overshoot, 52 pt keep-open past the sidebar, 24 pt vertical slack. Peek: scale from 0.001 + opacity, snappy 0.3 s, scrim black 30%. Dialog in y+30/blur 3, out y−30/blur 3, snappy 0.3 s. Toast opacity + blur 8→0, smooth 0.25 s. Split drops pull 45% toward the cursor within 50 pt, haptic on enter/exit. AI tool glow: three angular gradients, widths 4/8/12, blur 4/12/24, rotating forever at 2/2.5/3 s.

Tokens: squircle radii 4/6/8/12/16/24; 32 pt rows, 2 pt gaps, 20 pt folder indent, 206 pt minimum sidebar; two branch-free shadow tokens; unloaded tabs 55% opacity. No blur/vibrancy/Liquid Glass — Liquid Glass shipped in 1.1.1/1.2.0, removed in 1.2.1 as "did not match our calm browser philosophy"; sidebar is a static accent gradient blended 55% toward the window background. Flaws: Reduce Motion honored **only** in the separator; 38 animation literals outside the token file; tool glow and update card repaint every frame; a global `NSEvent` mouse monitor per window for edge reveal, running even while the sidebar is shown.

**Build, CI, release.** One Xcode project, one app scheme, 7 local SPM packages, 3 remote (Sparkle, Garnish pinned to an untagged commit, FaviconFinder). CI `macos-build.yml` on every PR/push to `develop`: unsigned Release on `macos-26`, launch on `macos-15`, alive after 20 s; **no tests**. Tag release: Developer ID, `--options runtime`, `notarytool --wait`, staple, UDZO DMG; Sparkle re-signed inside-out. Nine tag runs: 5:40–15:37, median **6:39**. Sparkle 2 + EdDSA; `sign_update`, DMG on the release, item appended to `appcast.xml` on `gh-pages`; `minimumSystemVersion` and `informationalUpdate` below build 110; notes from `CHANGELOG.md`; new build number per tag. Live feed: 16 items, latest `sparkle:version="119"`.

**Tests, habits.** No Xcode test target (`xcodebuild test` fails). `NookTabsCore` `swift test`: 63 test functions. Other logic via "Checks": `@main` `precondition` programs against shipped source, ~1,130 lines; all test code ~2,700 lines (incl. ~1,300 Swift, ~280 Rust). Gitflow; one worktree per agent; notes in gitignored `docs/`; user-visible text needs approval; AI use disclosed. Verification without focus theft: `open -g`, DevMCP over `curl`, read logs/JSON. Power/memory via `proc_pid_rusage` on a copy with its own bundle id. Launch-to-first-paint 2,147→607 ms and 3.5 GB suspended across six tabs are CLAIM.

## What rac should take (ranked)

Costs: **S** = days of one thread; **M** = 1–2 weeks; **L** = 3–6 weeks (INFERENCE).

1. **`personNamed` gate for `auto` (S–M).** Closes the gap where `auto` allows cross-site navigation and model-written typing with no card. Navigate/new tab to an unnamed site asks even at `auto`; so does a click whose button text the person didn't write. Nook applies it on-device only and has **no typing tool**, so rac adds two things itself (INFERENCE): exempt the attached tab's own site; ask before typing user-unsupplied text on an unnamed site. Use Chromium's registrable-domain helper, not Nook's seven suffixes. Pair with rac's first injection evals; reproduce the "small model obeyed planted text every run" case.
2. **Agent space (L).** rac's MCP server serves only its own agent, only during a run, and dies with AI off. Copy the shape: reserved space, created on first use, id marker, borrowed login profile fixed at creation, no focus theft, contained popups, no history/extensions, distinct frame, pulsing row. Keep rac's guard, cards, containment. **Do not** copy "token is the approval" for scripts. Needs a spike: does Chromium's capture-count keep a hidden agent tab rendering where Nook uses alpha 0 + 20,000 pt?
3. **Dev tools over MCP + Send to Agent (M).** `console`, `network` with `since` cursor, `perf`, `screenshot`, outline `snapshot` with changed-lines-only, `pick`/`selection`. Lets rac's own agents test rac with screenshots. Chromium has the data via DevTools; the work is a curated, permissioned surface, gated behind a developer setting.
4. **One motion-token file (S).** Adopt the four tokens and the space-swipe/edge-reveal constants above; honor Reduce Motion everywhere from day one.
5. **Tab-store safety (S–M).** Atomic writes coalesced 500 ms; dated daily backups 7 days; newest good backup on decode failure; read-only mode with an alert rather than overwrite. 30-day tombstones prepare sync; fractional keys make a move one write.
6. **Trails (M).** Child nests under opener; closing the parent promotes children; Back on a child with no history returns to the parent and closes it. Familiar to Arc refugees from Zen/Safari.
7. **Small micro-interactions (S each).** Separator becomes a travelling sine wave while work runs, paused when idle, spinner under Reduce Motion; magnetic split targets; space-dot hover name; toast blur 8 + opacity. Skip the rotating glow.
8. **Full-text history search (M).** Local FTS5, first 20,000 chars/page, off in incognito, deleted with the history row. Ship off by default or ask in onboarding; needs privacy review.
9. **Arc import details (S, inside planned import).** Read `StorableSidebar.json` as a tree; map Arc profiles to profiles named from `Local State`; favorites into each space of that profile; extensions by store id; keep the member card. Arc users reported no import feedback and duplicate spaces on repeat import (#143; flattening raised in comments, not the report).
10. **Live folders + favorite hover cards (M, after release).** Refresh on activation, never a timer; prefer a documented API and explicit opt-in over Nook's undocumented GitHub endpoint + cookies.
11. **Habits (S).** Launch-on-oldest-macOS smoke job; changelog sections become release/Sparkle notes; `informationalUpdate` for builds that can't install; `TRADEMARK.md`.

## What rac should avoid

- **Blocking system alerts and chat-wide "Allow All"** — rac's inline cards and per-site rules are better.
- **"The token is the approval"** for arbitrary JS on logged-in sessions.
- **Tools reading through the page's own JS world** — use isolated worlds or browser-side extraction.
- **Privacy-weak defaults**: typed text to Google after 125 ms, AI on, silent auto-install, MCP servers started at launch regardless of chat.
- **Changing bundle id or signing team** — stranded every 1.0.x install.
- **System-wide mouse monitors**; **animations that run forever**.
- **Style churn** (Liquid Glass in and out in two weeks) and **drifting docs**.
- **Switching engines.** WebKit's ceiling: Canvas LMS/Kaltura broken (#371), no Widevine (FairPlay only, CLAIM from #263 comments), no iCloud Keychain passkeys, updates only with macOS, no patching. Chromium is right for Arc refugees (INFERENCE).

## Caveats

- Nook was **not run**; motion feel, hover timing, and memory come from code. Performance claims (3x launch, 2,147→607 ms, 3.5 GB) and the 22-case injection eval rest on gitignored files; unverifiable (CLAIM).
- Doc drift: README says the organizer needs MLX (none resolves); `CLAUDE.md` says no iOS target (one exists) and that edge hover uses `NSTrackingArea` (global monitors; tracking modifier only on the 6 pt hotspot); it misdates the `v1.2.1` run (Actions: 2026-10-08).
- Blocker off by default on macOS (on for iOS) is unexplained, though `CLAUDE.md` calls blocking a top priority. Root `telemetry-id` has unknown purpose; nothing reads it.
- Open: Chromium capture-count for hidden agent tabs; calling `FoundationModels` without a large Swift bridge; actual user count (downloads mix installs/updates, no telemetry); whether PR #392 (Arc-like refresh) and #395 (interruptible space switching) merge; whether iCloud sync ships (it ignores trails).
